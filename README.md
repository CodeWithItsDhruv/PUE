# 📱 College Event Management App

Welcome to the **College Event Management App** – your one-stop solution for staying informed and registering for all the exciting activities happening on campus!

## 🚀 Features

- 🎉 **Easy Event Registration**: Seamlessly register for sponsored events organized by various college cells.
- 🗓️ **Stay Updated**: Never miss out on any event, workshop, or seminar again!
- 📲 **User-Friendly Interface**: Designed with students in mind for a smooth and intuitive experience.
- 🔔 **Notifications**: Get real-time updates and reminders for upcoming events.
- 💼 **Event Details**: View descriptions, timings, venues, and organizers for every event.

## 📱 Platform Support

- ✅ iOS

## 🏫 Why Use This App?

Gone are the days of missing out on college opportunities. With this app, all campus events are at your fingertips – join, track, and enjoy every moment of your college life.

## 🛠️ Tech Stack

- **Frontend**: Swfit, SwiftUi
- **Backend**: Firebase / Swift
- **Database**: Firebase Realtime DB / Firestore
